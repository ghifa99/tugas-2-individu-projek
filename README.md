# Es Teh Bim

## Deskripsi

Es Teh Bim merupakan website sederhana yang dibuat untuk menampilkan informasi dan menu es teh serta menyediakan fitur pemesanan. Website ini dibuat sebagai tugas pengembangan web menggunakan HTML, CSS, dan JavaScript.

#Fungsi Website

Website Es Teh Bim berfungsi untuk:
- Menampilkan informasi mengenai Es Teh Bim.
- Menampilkan berbagai pilihan menu es teh.
- Menambahkan produk ke pesanan sementara.
- Menghitung total harga pesanan.
- Menyediakan form pemesanan.
- Menampilkan hasil pesanan pengguna.

#Fitur Utama

#1. Home
Menampilkan informasi mengenai Es Teh Bim dan beberapa menu favorit.

#2. Menu
Menampilkan daftar menu:
- Es Teh Original
- Es Teh Lemon
- Es Teh Strawberry

Pengguna dapat menambahkan produk ke pesanan dan melihat total harga.

#3. Pesanan
Pengguna dapat mengisi nama, memilih menu, menentukan jumlah pesanan, dan melihat hasil pesanan.

#4. Responsive Design
Website dapat menyesuaikan tampilan pada desktop, tablet, dan handphone menggunakan CSS Media Query.

#Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- DOM Manipulation
- Array of Objects
- Event Handling
